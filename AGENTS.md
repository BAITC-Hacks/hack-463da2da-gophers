ТЗ: `HackAlem AI_ Career Quest - платформа геймификации жизненного цикла сотрудника..docx`
Датасет: `career_quest_dataset/case_1/career_quest_dataset/` (README.md внутри — обязательное чтение)

## Кто есть кто (3 трека агентов, каждый работает в СВОЕЙ директории)

| Агент | Кто запускает | Роль | Директория (только тут!) |
|---|---|---|---|
| **GLM** (opencode) | тимлид | AI-ядро: скоринг, LLM-обоснования, анализ профиля | `backend/app/ai/` |
| **Antigravity** | тимлид + Алмас | Backend: FastAPI, датасет, эндпоинты, загрузка профилей жюри | `backend/app/api/`, `backend/app/main.py` |
| **Codex** | Тим (доступен всем, но фронт — его трек) | Frontend: React UI сотрудника и HR, локализация | `frontend/` |

## Обязательное правило идентификации

Перед началом ЛЮБОЙ работы агент обязан объявить:

```
Я — <имя агента>. Моя зона: <директория>. Мой трек: <этапы из TODO.md>.
```

Если тебя просят сделать задачу вне твоей директории — не делай, ответь, что это зона другого агента.

## Правила работы

1. **Не трогай чужие директории.** Общие файлы (`AGENTS.md`, `TODO.md`, `docs/openapi.yaml`, `docker-compose.yml`) меняет только GLM.
2. **Каждый этап = коммит.** Формат: `feat(ai): ...` / `feat(api): ...` / `feat(front): ...`. Сначала `git pull`.
3. **Ядро задачи** — качество и объяснимость рекомендации (обоснование минимум по 3 факторам: грейд, разрывы навыков, история участия, требования следующего уровня). Не «бери минимальный навык».
4. **Критично:** жюри на защите загружает свои проверочные профили в формате датасета — решение обязано их принимать (конфликт однофакторных правил проверяется именно на них).
5. **Запрещено ТЗ:** публичные рейтинги сотрудников, очки за обязательные процессы, реальные персданные. Приватность: вовлечённость не видна другим сотрудникам.
6. Тайминги: отклик UI < 2 c, AI-рекомендация < 10 c. Запуск всего — одной командой (`docker compose up`).
7. Данные синтетические, вне хакатона не выносятся. Тексты UI — ru/kk/en (preferred_language из профиля).

## Стек

- Backend: Python 3.11, FastAPI, uvicorn. Порт 8000.
- Frontend: Vite + React + TypeScript. Порт 5173.
- LLM: OpenAI API (основная, gpt-4o-mini), NVIDIA API (фолбэк). Ключи в `.env`, НЕ коммитить.
