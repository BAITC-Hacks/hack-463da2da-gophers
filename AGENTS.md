## Кто над чем работает (треки, НЕ инструменты!)

| Трек | Кто | Директория (только тут!) |
|---|---|---|
| **AI-ядро / core** | тимлид (GLM) | `backend/app/ai/core/`, `backend/app/ai/contracts.py`, `backend/app/ai/recommender.py` |
| **AI-ядро / llm** | 2-й контекст тимлида (Codex) | `backend/app/ai/llm/` |
| **Backend** | Алмас (+ тимлид) | `backend/app/api/`, `backend/app/main.py` |
| **Frontend** | Тим | `frontend/` |

**Инструмент (Codex / Antigravity / GLM) — это просто инструмент, роль он НЕ определяет.**
Роль = трек + директория. Если Алмас запускает Codex для бека — Codex работает по треку Backend в `backend/app/api/`. Если Тим запускает Codex для фронта — трек Frontend в `frontend/`. Отказ «я Codex, поэтому только фронт» некорректен.

**Общий шов AI-ядра:** `backend/app/ai/contracts.py` — единственный файл на границе core↔llm. Меняет только GLM. Codex (llm) реализует `explain()` строго по типам из `contracts.py`, описание задачи — в `backend/app/ai/llm/__init__.py`.

## Обязательное правило идентификации

Перед началом ЛЮБОЙ работы агент обязан объявить:

```
Работаю по треку <AI-ядро|Backend|Frontend>. Моя зона: <директория>. Мой инструмент: <Codex|Antigravity|GLM>.
```

Если тебя просят сделать задачу вне твоей директории — не делай, ответь, что это зона другого трека.

## Правила работы

1. **Не трогай чужие директории.** Общие файлы (`AGENTS.md`, `TODO.md`, `docs/openapi.yaml`, `docker-compose.yml`) меняет только GLM.
2. **Каждый этап = коммит.** Формат: `feat(ai): ...` / `feat(api): ...` / `feat(front): ...`. Сначала `git pull`.
3. **ЗАПРЕЩЕНЫ `git add -A` и `git add .`** — только конкретные свои пути (`git add backend/app/ai/llm`). Иначе заста́жишь чужие полуготовые файлы. Пуш сразу после коммита.
4. **Ядро задачи** — качество и объяснимость рекомендации (обоснование минимум по 3 факторам: грейд, разрывы навыков, история участия, требования следующего уровня). Не «бери минимальный навык».
5. **Критично:** жюри на защите загружает свои проверочные профили в формате датасета — решение обязано их принимать (конфликт однофакторных правил проверяется именно на них).
6. **Запрещено ТЗ:** публичные рейтинги сотрудников, очки за обязательные процессы, реальные персданные. Приватность: вовлечённость не видна другим сотрудникам.
7. Тайминги: отклик UI < 2 c, AI-рекомендация < 10 c. Запуск всего — одной командой (`docker compose up`).
8. Данные синтетические, вне хакатона не выносятся. Тексты UI — ru/kk/en (preferred_language из профиля).

- Frontend: Vite + React + TypeScript. Порт 5173.
- LLM: OpenAI API (основная, gpt-4o-mini), NVIDIA API (фолбэк). Ключи в `.env`, НЕ коммитить.
