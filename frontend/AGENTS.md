## Что ты строишь

1. **Каркас**: Vite + React + TypeScript, роутинг, тёмная/светлая тема, axios-клиент по контракту `docs/openapi.yaml` (пока бек не готов — мок-данные по тем же схемам).
2. **Экран сотрудника**: профиль (роль, грейд, стаж, цель), радар навыков «текущий vs требования next grade» (critical_skills выделить), история активностей.
3. **Рекомендации (ядро UX)**: карточки 1–3 шагов, факторы обоснования по отдельности (explainability!), кнопка «Выполнено» → анимация сдвига навыков/траектории. Скелетоны: UI < 2 c, AI до 10 c.
4. **HR-дашборд**: проседающие навыки, сотрудники без рекомендаций, участие по активностям.
5. **Локализация ru/kk/en** (язык из preferred_language профиля), E2E-сценарий из ТЗ, проверка приватности (вовлечённость не видна другим сотрудникам).
