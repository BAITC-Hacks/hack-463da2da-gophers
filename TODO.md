# Career Quest — план разработки (HackAlem AI, Halyk Bank)

## Кто над чем работает (треки, НЕ инструменты!)

| Трек | Кто | Директория (только тут!) |
|---|---|---|
| **AI-ядро / core** | тимлид (GLM) | `backend/app/ai/core/`, `contracts.py`, `recommender.py` |
| **AI-ядро / llm** | 2-й контекст тимлида (Codex) | `backend/app/ai/llm/` |
| **Backend** | Алмас (+ тимлид) | `backend/app/api/`, `backend/app/main.py` |
| **Frontend** | Тим | `frontend/` |

Инструмент (Codex / Antigravity / GLM) — просто инструмент, роль он НЕ определяет. Алмас может делать бек любым инструментом, Тим — фронт любым.

**Правило идентификации:** перед началом работы каждый агент ОБЯЗАН объявить:
`Работаю по треку <AI-ядро|Backend|Frontend>. Моя зона: <директория>. Мой инструмент: <...>.`
Задачи вне своей директории не выполнять — это зона другого трека. Подробности: `AGENTS.md` в корне и в каждой директории.

**Стек:** FastAPI (Python 3.11) + React (Vite, TS) · **LLM:** OpenAI API (осн.), NVIDIA API (фолбэк) · **Запуск:** `docker compose up` одной командой

**Директории (не конфликтуем):** `backend/app/ai/` — GLM · `backend/app/api/` — Codex · `frontend/` — Gravity

**Правила коммитов:** каждый этап = коммит, формат `feat(ai): ...` / `feat(api): ...` / `feat(front): ...`
